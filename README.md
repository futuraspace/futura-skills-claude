# futura-skills-claude

Skills y mods de Claude para Futura Space.

## Instalar en un ordenador nuevo

```
/plugin marketplace add <usuario>/futura-skills-claude
/plugin install futura-skills --marketplace futura-skills-claude
/plugin install cowboy-button --marketplace futura-skills-claude
```

## Contenido

- `plugins/futura-skills/skills/cowboy`: skill `/cowboy`, optimiza un prompt.
- `plugins/cowboy-button`: botón 🤠 en la interfaz de Code que hace lo mismo con un clic.

## Añadir una skill nueva

Crea `plugins/futura-skills/skills/<nombre>/SKILL.md`, súbela y sube la versión en `plugins/futura-skills/.claude-plugin/plugin.json`.
